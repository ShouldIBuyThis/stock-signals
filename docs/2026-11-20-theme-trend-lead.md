# 앞설 테마 '상승 주도' 순위 — 일봉 200선 vs 주봉 120선·40선 (사전 등록 · 결과 보기 전 · 2026-11-20)

사용자 지시: 앞설 테마 TOP5를 [상승 주도] [단기 반등] 두 모드로 나눈다. 상승 주도는 200일선 위 비율을 기본으로,
5거래일 뒤 실제 종가 수익률과 전체 테마 대비 상대 강도로 연구한다. 주봉 120선은 바로 넣지 말고 200선과 결합했을 때
5·10일 수익률·승률이 좋아지는지 먼저 본다. 주봉 40선(일봉 200선과 비슷한 기간)도 같이 봐서 '기간이 길어서 생긴 효과'인지 가른다.
도구 `tools/theme-trend-lab.py` · 읽기 전용 · CI 로그만.

## 0. 자료의 성격
- 2017~21 학습 · 2022~23 검증 · 2024~26 재확인 — **모두 이전 테마 연구에서 이미 본 기간**. 독립 검증은 화면 반영 뒤 실전 원장뿐.
- 테마 구성 = 지금 관심종목(미국 상장 · 레버리지 아님) → 생존 편향. 늦게 상장한 종목은 상장 뒤부터.
- 이동평균: **일봉 200선 = 200거래일 단순 이동평균(MA200)**. 주봉 = 금요일 마감 주봉(그날까지 완성된 주봉만), 주봉 120선·40선 = 완성 주봉 종가 120·40개 평균.
  '주봉 n선 위' = 그날 일봉 종가 > 마지막 완성 주봉의 n선. '기울기 상승' = 마지막 완성 주봉 n선 > 4주 전 n선.
- 주봉 120선은 상장 후 120주(약 2년 4개월)가 지나야 계산된다. **계산 가능 종목 수를 테마·연도별로 공개**하고, 테마 값은 계산 가능 종목 2개 이상일 때만 낸다.

## 1. 판정 지표 (종가 기준 · 진입 = 신호일 종가)
- 테마 수익 = 구성종목(미국 · 레버리지 아님) 동일가중 h거래일 뒤 종가 수익 (h = 3·5·10).
- **종가 상승 승률** = 테마 h일 수익 > 0. **상대 강도 승률** = 테마 h일 수익 > 그날 모든 테마의 중앙값. 평균 수익. (+1% 도달은 참고로만)
- 추천 TOP5의 각 테마를 한 건으로 센다(순위별로도 집계). 같은 날·연속 날짜 겹침 → 10거래일 블록 부트스트랩 90% 구간.

## 3. 판정 (사전 고정)
- 화면 '상승 주도' 순위는 **T1(200선 위 비율)** 로 시작한다.
- 후보 Tk가 T1을 대신하려면: 5일 상대 강도 승률이 T1보다 학습·검증 **모두 +2%p 이상** ∧ 검증 90% 구간 하한 > 0 ∧ 재확인 Δ ≥ 0 ∧ 학습+검증 5일 평균 수익 ≥ T1.
- 주봉 120선 효과가 '기간이 길어서'인지: T2·T3의 개선이 T4·T5에서도 비슷하면 주봉 120선 고유 효과로 보지 않는다.
- 주봉 지표가 이겨도 화면에 바로 넣지 않는다 — 원장(signals.json)은 1년치라 주봉 120선을 못 만든다. 넣으려면 데이터 수집(main.py) 변경이 필요해 사용자 결정으로 넘긴다.
- **상승확률은 만들지 않는다.** 상승 주도 모드는 '추세 순위'와 과거 실제 승률(이 연구 집계 · 표본 수 포함)만 보여 준다.

## 4. 화면에 옮길 숫자

### 5-3. 솔직하게 적을 점 — T1도 '앞서는' 순위는 아님
| 기간 | T1 TOP5 5일 종가 상승 | 5일 상대 강도 | 5일 평균 |

- 상대 강도(그날 전체 테마 가운데값보다 더 오름)가 모든 후보·모든 기간에서 **50% 아래**(45~50%). 200선 비율 상위 테마는 '추세가 강한 테마'일 뿐, 다음 5일에 다른 테마보다 더 오를 확률이 높다는 근거는 없다.
- 그래서 화면은 계속 '추세 순위 · 확률 아님'으로 표시하고, 상세에 상대 강도 승률(50%가 보통)을 그대로 보여 준다.
- **정정(2026-11-20 캔들 연구 §7-3)**: '50%가 보통'은 틀린 기준. 상대 강도는 가운데값 '초과'만 세므로 무작위 TOP5도 45~48%(학습 46 · 검증 45 · 재확인 48%)다.
  T1은 무작위 대비 +0 / +1 / +1%p — 결론(앞선다는 근거 없음)은 같고, 대신 −3% 이하 비율·최대 불리가 무작위보다 조금 작다. 화면 문구를 고쳤다.
