# 장중 상승 ⭐ 후보 탐색 2차 — 사전 등록 (2026-11-09, 결과 전 커밋)

사용자 지시: 상승형 이름만으로 ⭐ 금지 · 실제 +15분 상승 적중 ≥61% 조건을 찾되 무리한 조정·사후 선별 금지 · 미장/국장 분리 · 국장 20분 지연 반영.
1차(docs/2026-11-09-intraday-bull.md)는 '패턴 단독·맥락'으로 72후보 중 0개. 이번 2차는 하락 ⚠️ 후보를 찾은 것과 **같은 구조**
(= 판정 상태에 **새로 들어간** 봉 × 그 봉의 대표 캔들)를 상승 쪽에 그대로 적용한다. 계산은 화면 함수 `idStarEvents()`로만 한다(화면과 같은 정의).

## 후보 격자 (미리 고정 · 이 밖은 보지 않는다)
- 상태(새 진입): 🟢 go · 🟡 wait · 🟡 pull · 🔴 up · ⚪ flat · 🔵 down(하락 주의 속 반등)  — 6개
- 대표 캔들: 망치형 · 역망치형 · 잠자리 도지 · 양봉 마루보주 · 장대양봉 · 일반 양봉 · 상승장악형 · 상승잉태형 · 관통형 · 집게바닥 · 샛별형 · 적삼병 · 상승 확인 잉태(3봉) — 13개
- 추가 6개: 위 격자 중 (상승장악형·망치형·샛별형) × (VWAP 아래 저가, 상태 무관) · 긴 아랫꼬리 양봉(전체 이름 목록 기준) × (VWAP 아래 / 30분 상승 / 30분 하락)
- 총 6×13 + 6 = **84칸**. 기준선 48%·n 15~30이면 우연히 61%를 넘는 칸이 여러 개 나올 수 있다 → 아래 검증 없이 ⭐ 금지.

## 판정
- 성과: 다음 5분봉 시가 진입 · +5·+15분(핵심) · +30분 · 손익비 · 비용 0.05% 차감. 같은 봉의 여러 칸은 각 칸에 들어가되 합계는 거래 1건.
- 연구 후보: 전체 +15분 상승 ≥61% · n≥15.
- 워크포워드 검증 통과: 블록1→2, 블록1+2→3 **두 번 모두** 학습(n≥15 · ≥61%) 선택 + 검증(n≥10 · ≥55% · 같은 기간 기준선 +3%p 이상).
- 미장/국장 따로 적고, 국장은 ② 20분 뒤 확인 기준도 적는다.
- 후보가 나와도 검증 실패면 '미검증 연구 후보 · 매매 신호 아님'. 화면 ⭐는 사용자 확인 뒤에만. 기준·숫자는 결과를 보고 바꾸지 않는다.
