# 앞설 테마: 순신고가 강도·신저가 조합 → 현행 TOP3보다 나으면 적용 (사전 등록 · 결과 보기 전 · 2026-11-19)

사용자 지시: "순신고가 강도 단독 · 순신고가 강도 증가 ∩ 신저가 감소 · 200일선 위 비율 상위 ∩ 순신고가 강도 상승 · 기존 TOP3 ∩ 신저가 둔화 —
가장 승률 좋은 조합을 앞설 테마로, 적용까지". 정의는 기존 그대로(docs/2026-11-18-theme-redesign.md §1 · tools/theme-redesign-lab.py).

## 0. 자료의 성격
- 10년 백필(관심종목 소급 · 생존 편향). 순신고가 강도 단독은 이미 두 번 봤다(theme-hl-rank · theme-redesign) → **재확인 2024~2026은 참고 · 독립 아님**.
- 기간: 학습 2017-02~2021-12 · 검증 2022~2023 · 재확인 2024~2026-11.

## 1. 정의(바꾸지 않음)
- hr·lr = 구성종목(미국 상장 · 레버리지 아님 · 2종목↑) 중 종가 ≥ 52주 고가×0.99 / ≤ 52주 저가×1.01 비율.
- **순신고가 강도 net5** = hr 5일 평균 − lr 5일 평균. **증가 Δ5** = net5(오늘) − net5(5일 전). **신저가 감소** lrΔ5 = lr5(오늘) − lr5(5일 전) < 0.
  **신저가 둔화** lowstop = 직전 10일 lr5 최고 ≥ 10% ∧ 오늘 lr5 ≤ 그 최고 − 5%p. ab200 = 200일선 위 종목 비율.
- 기준선 **V0 = 현행 화면 앞설 테마**(themeMultiRank). 동률은 모두 V0 순서로 끊는다(동률 처리로 ±3~4%p 흔들린 지난 결과 반영).

## 2. 후보(이것만)
- K1 순신고가 강도 단독: net5 높은 순 TOP3.
- K2 (Δ5 > 0 ∧ lrΔ5 < 0) 테마를 net5 순으로 먼저, 모자라면 V0 순으로 채움. 이웃: K2b 같은 집합을 V0 순 · K2c (Δ5 ≥ 0 ∧ lrΔ5 ≤ 0).
- K3 ab200 상위 n ∩ Δ5 > 0 (ab200 순), 모자라면 ab200 순으로 채움 · n = 4·5·6.
- K4 V0 순서에서 신저가가 늘어나는 테마(lrΔ5 > 0)를 건너뛰고 TOP3 · 이웃: K4b V0 TOP3 ∩ lrΔ5 < 0만(0~3개) · K4c V0 TOP3 ∩ 신저가 둔화만(0~3개).

## 3. 비교
- 같은 날 · 같은 추천 개수의 V0 상위와 짝 비교(적중 = 추천 평균 5·10일 수익 > 그날 모든 테마 중앙값 · 화면 themeCheck와 같음).
- 10거래일 블록 부트스트랩 90% 구간 · 5거래일 간격 표본 · 연도별 · 가장 많이 추천된 테마 비중 · 추천 0개인 날 비율.

## 4. 적용 판정(사전 고정)
**적용 가능** = 학습·검증 두 기간 모두 5일 적중 +2%p↑(V0 대비) ∧ 검증 90% 구간 하한 > 0 ∧ 두 기간 10일 적중 V0 이상 ∧
학습+검증 합산 평균 수익 5·10일 V0 이상 ∧ 재확인 5일 Δ ≥ 0(뒤집히지 않음) ∧ 같은 계열 이웃 하나 이상이 학습·검증 모두 Δ5 > 0(고원) ∧ 추천 0개인 날 ≤ 20%.
- 여럿이면 검증 5일 개선폭이 가장 큰 것. **없으면 현행 유지**(덜 맞는 산식으로 바꾸지 않는다).
- 적용 시 화면 산식은 원장(hist의 pct_from_high·pct_from_low·ma200)으로 같은 정의를 계산하고, 바꾼 날부터 전진 기록을 따로 쌓는다. `node tools/keepcases.js` 확인.
