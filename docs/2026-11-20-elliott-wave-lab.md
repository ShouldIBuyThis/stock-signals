# 파동(엘리어트) 연구 — "조정 파동으로 내려오면 빨리 되돌린다" (사전 등록 · 결과 보기 전 · 2026-11-20)

사용자가 보여 준 글(X, SOXX 매매 후기)의 주장을 기계적 규칙으로 옮겨 검증한다. 읽기 전용 · CI 로그만. 도구 `tools/wave-lab.py`.

## 0. 글의 주장 → 검증할 가설
| 글 | 가설 |
|---|---|
| "내려오는 구조가 임펄스가 아니면(조정 파동이면) 끝나면 빠른 시간 안에 되돌린다" | **H1** 하락 구간이 3파(ABC)로 끝난 자리는 5파 임펄스로 끝난 자리보다 하락 시작점(H0)까지 **빨리 전부** 되돌린다 |
| "C파 자리에서 임펄스가 아닌 조정 파동 → terminal impulse(끝 대각) → 빠르게 전부 되돌리며 확정" | **H2** 겹치는 5파(대각·끝 파동)로 끝난 하락은 임펄스보다 빨리 전부 되돌린다 · **H4** 상승 쪽 거울: 겹치는 5파 상승(끝 대각)은 임펄스 상승보다 빨리 출발점까지 되돌린다(익절 경고 쪽) |
| "아무 차트나 적용 안 함. 거래량·참여자 많은 지수·주목 섹터·M7에서 잘 맞음" | **H3** H1의 차이는 '지수·섹터 ETF·M7'에서 나머지 종목보다 크다 |
| "이전 파동을 딱 0.618 되돌림 · flat" | 기술만(가설 아님): 0.618 근처·flat(B가 A를 90%↑ 되돌림)·zigzag 나눠 성적 표시. 피보나치 되돌림은 2026-08-23 연구(fib-lab)에서 이미 기각됨 |

이미 기각된 것과 겹치지 않게: 피보 수준 자체(08-23 기각) · 5분봉 3파 시작·1파 돌파(11-10 기각)는 다시 재지 않는다. 이번에는 **하락(상승) 구조의 '모양'이 그 뒤 되돌림 속도를 가르는가**만 본다.

## 1. 자료
- 일봉 10년(야후 auto_adjust) · 60분봉 730일(야후 한도). 진입 = **신호 봉 종가**(진입 기준 규칙 2026-11-12).
- 종목: 관심종목(레버리지 제외) + 유동성 대조용 ETF `QQQ SPY SOXX SMH IWM DIA XLK`.
- 그룹 **지수·대형** = 위 ETF 7 + M7(AAPL MSFT NVDA AMZN GOOGL META TSLA) + 069500.KS·229200.KS. 나머지 = **개별·소형**.
- 현재 관심종목 기준이라 생존 편향이 있다(늦게 상장한 종목은 상장 뒤부터).

## 2. 파동 정의 (리페인트 금지 — 신호 봉까지 확정된 피벗만)
- ATR14(단순 평균 TR). 지그재그: 고점 확정 = 진행 중 고점에서 **종가**가 θ·ATR(그 고점 봉) 이상 내려온 봉, 저점 확정은 거울.
- 큰 파동 θB = 3 · 작은 파동 θS = θB/3 = 1 (기본). 이웃: θB 2·4 (θS = θB/3), θB 3 · θS 1.5.
- **사건(하락 쪽)**: 작은 파동 저점 pi가 확정된 봉 pc에서 ① 그 시점 가장 최근 확정된 큰 피벗이 고점 H0 (큰 파동은 아직 하락 중) ② pi가 H0 뒤 최저가 ③ 하락폭 H0 − 저가(pi) ≥ θB·ATR(H0).
- H0 뒤 확정된 작은 피벗 수 k(= 하락 다리 수)로 분류:
  - k = 1 단일 다리 · k = 3 **ABC(조정)** · k ≥ 7 복합 조정
  - k = 5: 4파 고점 < 1파 저점(겹침 없음) ∧ 3파가 1·3·5 중 가장 짧지 않음 → **임펄스** · 4파 고점 ≥ 1파 저점(겹침) → **대각(끝 파동)** · 나머지 → 5파 기타
- 상승 쪽(H4)은 모든 정의를 위아래로 뒤집는다.
- 한 하락에서 k = 1·3·5…마다 사건이 하나씩 나올 수 있다(그 시점 사람도 그렇게 센다). 같은 하락의 사건끼리 겹치므로 구간은 **월 단위 군집 부트스트랩**.

## 3. 결과 지표
- T = 하락에 걸린 봉 수(H0 → pi). **빠른 전부 되돌림** = 신호 뒤 T봉 안에 고가가 H0 이상(주 지표). 보조: 10·20봉 안 전부 되돌림 · T봉 안 절반 되돌림 · T봉 안 저점 이탈(pi 아래).
- 종가 수익 1·5·10·20봉 · 기준선 = 같은 그룹·같은 봉 단위 모든 봉.

## 4. 판정 (사전 고정)
**H1 성립** = 일봉에서 ABC − 임펄스 '빠른 전부 되돌림' Δ ≥ +5%p가 **앞·뒤 절반 모두**(앞 = ~2021-06 · 뒤 = 2021-07~) ∧ 전체 90% 군집 구간 하한 > 0 ∧ 10봉 수익 Δ ≥ 0 두 절반 모두 ∧ 이웃 θ(θB 2·4) 둘 다 Δ > 0(고원) ∧ 각 칸 표본 50↑(§5-1).
60분봉은 같은 기준을 따로 적용(절반 = 기간 가운데 날짜).
- H2: 대각 − 임펄스로 같은 기준. H3: 지수·대형 그룹 Δ − 개별·소형 Δ의 90% 구간 하한 > 0. H4: 상승 대각 − 상승 임펄스, '출발점까지 전부 되돌림'으로 같은 기준.
- **추가 조건(실제 결과 보기 전 추가 · 2026-11-20)**: 가짜 무작위 가격으로 문법을 확인하다가, 파동 구조가 전혀 없는 무작위 가격에서도
  ABC − 임펄스 Δ가 +8.5%p, 대각 − 임펄스 +13.7%p로 '유의하게' 나왔다. 임펄스는 정의상 길고 깊은 하락이라 'T봉 안 H0 복귀'가 원래 어렵기 때문이다(분류가 만드는 착시).
  그래서 H1·H2·H4는 ① 같은 종목의 봉 순서를 무작위로 섞은 가격(파동 구조 없음) 20회로 같은 계산을 한 **귀무 Δ의 95백분위를 실제 Δ가 넘어야** 하고
  ② 하락 깊이(ATR 배수 3·5·8·12 칸) 안에서 비교한 **깊이 맞춤 Δ ≥ +5%p**여야 성립. H3는 귀무 95백분위를 넘어야 성립.
- 성립해도 이번에는 **보고만** 한다(화면 반영은 사용자 결정). 성립 안 하면 그대로 기록한다.
- 결과 숫자를 보고 정의·θ·기간을 바꾸지 않는다. 바꾸면 새 사전 등록으로 따로 적는다.
