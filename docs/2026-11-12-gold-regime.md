# 🏆 황금신호 — 시장 국면별 성적 (사전 등록 · 2026-11-12 · 결과 전)

사용자 질문: "황금신호 약세장 승률이 엄청 좋은 거면 강세장엔 더 좋았겠네? 1년치 연구."
황금신호 산식은 바꾸지 않는다. 기존 3년 도구(tools/gold-3y-lab.js)에 국면 분해만 덧붙인다(`REGIME=only`).

- 대상: 황금신호의 **일봉 쪽**(미장 = 일봉 등급 ∩ 상승 캔들 · 장중 5분 ▲은 야후 5분봉이 60일뿐이라 1년에 걸 수 없음 / 국장 = 일봉 등급 ∩ (상승 캔들 또는 %B≤10) — 현행 그대로).
- 국면(그날까지 값만): 미장 QQQ · 국장 KODEX200(069500). **상승** = 종가 > 200일선 ∧ 60일 수익 > 0 · **하락** = 종가 < 200일선 ∧ 60일 수익 < 0 · 그 밖 **횡보**.
- 성과: 신호일 종가 기준 3·5·10거래일 뒤 상승 비율(±1% 밖 · 보합 제외)과 평균 수익 · 같은 국면 모든 종목·날(기준선)과 나란히.
- 기간: **최근 1년(252거래일)** 을 먼저, 3년 전체를 같이.
- 가설: "약세장에서 좋았으면 강세장에선 더 좋다". 판단: 상승 국면 황금 5일 상승 비율이 하락 국면보다 높고, 기준선 대비 차이도 상승 국면이 더 크면 '맞음'.
  국면별 건수가 15건 미만이면 '표본 부족'(§5-1). 결과로 산식·문턱을 바꾸지 않는다.
- 같이 손본 것: `gold-3y-lab.js`·`gold-history-cands.js`·`test-gold-signal.js`의 '상승 캔들' 판정이 화면 sbGoldCands와 같게 `noGold`(🎯 Root 타격 연구 후보)를 뺀다 — 화면과 도구가 어긋나지 않게.
