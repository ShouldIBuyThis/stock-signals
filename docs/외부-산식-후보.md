# 외부 산식 후보 — 기록 전용 (적용 안 함)

사용자가 다른 도구에서 쓰는 매매법을 인수인계용으로 옮겨 적은 문서다.
**지금 사이트 산식에는 한 줄도 반영돼 있지 않다.** 나중에 검토할 때
"무엇을 하려던 것이었나"를 잃지 않기 위한 기록이다.

기록 시점: 2026-08-21 · 출처: 사용자 제공(외부 도구 화면 캡처 텍스트)

---

## 1. 페어 리버설 (Pair Reversal)

**핵심 아이디어** — 서로 다른 두 개의 선(추세선 + 넥라인)이 좁혀지다가
**같은 봉 또는 1봉 차로 함께 돌파**되는 지점을 반전 자리로 본다.
선 하나만 깨지는 것과 둘이 같이 깨지는 것을 다르게 취급한다.

### 판정에 쓰는 요소

| 요소 | 설명 |
|---|---|
| **추세선 터치 횟수** | 상승/하락 추세선이 몇 번 닿았는지 (3번·5번 등) |
| **넥라인 반응 횟수** | 수평 넥라인에서 몇 번 반응했는지 (2번·3번 등) |
| **동시 돌파** | 두 선을 같은 봉에서 또는 1봉 차로 함께 돌파 |
| **수렴 배율** | 두 선 사이 간격이 몇 배 좁혀졌는지 (10.8배 · 19.7배 · 24.5배) |
| **상위프레임 매물대** | 더 큰 시간틀의 매물대에서 몇 번 반응했는지 (5번·9번) |
| **RSI 다이버전스** | 가격과 RSI의 방향 불일치 |
| **거래량** | 수렴 구간의 거래량 감소 / 돌파 시 거래량 배율 (2.7배) |
| **리테스트 지지** | 돌파 후 되돌림에서 지지 확인 |

### 실제 사례 (사용자 기록)

| 종목 | 방향 | 근거 | 진입 | 손절 | 목표 | 결과 |
|---|---|---|---|---|---|---|
| IP | ▼ 하락 | 상승추세선 3번 + 넥라인 3번 동시 하향 돌파 · RSI 다이버전스 · 거래량 감소 · 상위프레임 9번 반응 · **24.5배 수렴** | $37.93 | $41.31 | $31.16 | 진행 중 |
| ODFL | ▼ 하락 | 상승추세선 5번 + 넥라인 3번, **1봉 차** 하향 돌파 · 상위프레임 5번 반응 · 리테스트 지지 · **10.8배 수렴** | $199.96 | $213.74 | $172.40 | 진행 중 |
| URNM | ▲ 상승 | 하락추세선 3번 + 넥라인 2번 동시 상향 돌파 · 상위프레임 5번 반응 · 리테스트 지지 · **19.7배 수렴** · 돌파 거래량 2.7배 | $56.81 | $55.41 | $59.60 | **−1.00R** |

손익비 계산(진입·손절·목표 기준)
- IP   손절폭 +8.9% / 목표폭 −17.8% → 약 **2.0R**
- ODFL 손절폭 +6.9% / 목표폭 −13.8% → 약 **2.0R**
- URNM 손절폭 −2.5% / 목표폭 +4.9% → 약 **2.0R**

→ 세 건 모두 **목표 R을 2.0으로 고정**해 잡았다. 진입 대비 손절폭이
종목 변동성에 따라 2.5%~8.9%로 다르고, 목표는 그 2배로 자동 산출된 형태다.

## 2. Root 타격 (Root Strike)

**핵심 아이디어** — 유동성 사냥(스윕) 뒤의 되돌림을 점수로 채점해
기준 점수 이상일 때만 진입한다. 페어 리버설과 달리 **점수제**다.

### 채점 요소

| 요소 | 설명 |
|---|---|
| **거대 유동성 스윕** | 직전 고/저점을 크게 훑고 되돌아온 움직임 |
| **반전 변위** (displacement) | 스윕 직후 반대 방향으로 강하게 밀어낸 봉 |
| **되돌림 확인** | 변위 구간으로 되돌아와 지지/저항이 확인됨 |
| **레벨 중첩** | 여러 근거 레벨이 같은 가격대에 겹침 |

점수는 **75~85점**대가 관측됐고, 요소가 하나 더 붙을 때마다 10점씩
올라간 것으로 보인다(75 = 스윕+변위+되돌림, 85 = 거기에 레벨 중첩).

### 실제 사례 (사용자 기록)

| 종목 | 방향 | 점수 | 근거 | 진입 | 손절 | 목표 |
|---|---|---|---|---|---|---|
| IBKR | ▼ 하락 | **85점** | 거대 유동성 스윕 · 반전 변위 · 되돌림 확인 · **레벨 중첩** | $90.39 | $98.18 | $74.80 |
| UBER | ▼ 하락 | 75점 | 거대 유동성 스윕 · 반전 변위 · 되돌림 확인 | $75.24 | $82.61 | $60.50 |
| XYZ | ▼ 하락 | 75점 | 거대 유동성 스윕 · 반전 변위 · 되돌림 확인 | $77.88 | $87.18 | $59.28 |

손익비
- IBKR 손절폭 +8.6% / 목표폭 −17.2% → 약 **2.0R**
- UBER 손절폭 +9.8% / 목표폭 −19.6% → 약 **2.0R**
- XYZ  손절폭 +11.9% / 목표폭 −23.9% → 약 **2.0R**

→ 여기서도 **목표 R = 2.0 고정**이다. 두 매매법이 같은 리스크 관리
규칙(손절폭의 2배를 목표로)을 공유한다.

## 3. 이 사이트에 붙일 수 있나 — 솔직한 격차

없는 능력을 있다고 적지 않는다. 지금 데이터로 되는 것과 안 되는 것을 가른다.

### ✅ 이미 있는 것

| 요소 | 우리 쪽 대응 |
|---|---|
| 넥라인 반응 횟수 | **`resTouchCount()`** — 최근 20거래일 중 저항선 ±1.5% 접촉 횟수를 이미 센다(🔨 뱃지) |
| 상위프레임 매물대 | `res_mid`·`sup_mid`(60일 고저) · `high_52w`·`low_52w` |
| RSI 다이버전스 | RSI는 있으나 **다이버전스 판정은 없다** — 가격 고점/저점 대비 비교 로직을 새로 짜야 한다 |
| 거래량 배율 | `vol_ratio`(20일 평균 대비) · `vol3_ratio` |
| 손절/목표 자동 산출 | `cartLevels()`가 지지·저항을 주지만 **R 기반 목표 계산은 없다** |

### ❌ 없는 것 (새로 만들어야 함)

| 요소 | 왜 없나 |
|---|---|
| **추세선 자동 인식** | 두 점 이상을 잇는 사선(斜線)을 찾는 로직 자체가 없다. 우리는 수평선(고저점)만 쓴다 |
| **두 선의 수렴 배율** | 추세선이 없으니 간격도 없다 |
| **동시 돌파 판정** | 위 둘이 선행돼야 한다 |
| **유동성 스윕 / 변위** | 일봉 종가만 저장한다. 스윕은 **봉 안의 고저·꼬리**를 봐야 하는데 `high`·`low`는 지표 계산에만 쓰고 hist에 저장하지 않는다 |
| **상위프레임** | 주봉·월봉을 만들지 않는다(일봉 전용) |
| **분봉** | 없다. Root 타격은 분봉 기반일 가능성이 크다 |

### 붙인다면 순서

1. **hist에 `high`·`low` 꼬리 추가** — `HIST_FIELDS` 꼬리에 덧붙이면 원장 규칙에 안 어긋난다.
   이게 있어야 스윕·변위·꼬리 판정을 나중에라도 할 수 있다. **지금 안 쌓으면 나중에 소급 불가**다.
2. **주봉 집계** — 일봉을 5개씩 묶으면 상위프레임 매물대가 생긴다. 새 조회 없이 계산만으로 가능.
3. **추세선 인식** — 최근 N봉의 고점/저점에 회귀선을 맞추는 방식. 가장 품이 크다.
4. **R 기반 목표** — 진입·손절만 정하면 목표는 산술이다. 화면 표시부터 시작할 수 있다.

⚠ 검증 없이 붙이지 않는다. 위 사례는 **3+3건**이고 그중 결과가 나온 건
URNM −1.00R 하나뿐이다. 방법론 §5-1 기준 '신뢰 불가' 구간이므로,
붙이더라도 **표시 전용으로 시작해 표본을 쌓은 뒤** 산식 편입을 검토한다.
