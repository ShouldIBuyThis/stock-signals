# 장중 상승 반전·지속 캔들 심층 연구 — 사전 등록 (2026-11-09, 결과 전 커밋)

판정·점수·등급·화살표·원장 불변. 패턴은 `index.html` `idCandleFeat()` 하나에서 나온다(연구 도구는 문자열로 추출).
이번에 이름 4개를 **기존 목록 뒤에만** 추가(긴 아랫꼬리 양봉 · 저점 상승형 · 십자샛별형 · 상승 확인 장악(3봉)=Three Outside Up) → 앞선 연구의 대표패턴은 그대로.

## 1. 대상 (모두 '마지막 봉이 확정된 시각'에 감지 · 미래 봉 없음)
- 1봉: 망치형 · 역망치형 · 잠자리 도지 · 긴 아랫꼬리 양봉(양봉·아랫꼬리 ≥50%·몸통 ≥20%) · 양봉 마루보주
- 2봉: 상승장악형 · 상승잉태형 · 관통형 · 집게바닥 · 저점 상승형(직전 음봉 · 저가 상승 · 종가 > 직전 고가)
- 3봉: 샛별형 · 십자샛별형(가운데 몸통 ≤10%) · 적삼병 · 상승 확인 잉태(3봉)=Three Inside Up · 상승 확인 장악(3봉)=Three Outside Up
- 조합(이름 없는 수치): 아랫꼬리 ≥0.5 × 거래량 배수(<1 / 1~2 / ≥2) × 지지 회복(저가 < 기준 & 종가 ≥ 기준; 기준 = VWAP / 15분 지지 S / 당일 시가)

## 2. 사건과 평가
- 5분 경계마다 확정 봉만 넣어 idMtf → 마지막 확정 봉에 idCandleFeat. **사건 = (종목, 봉) 1건**. 한 봉에 여러 패턴이 겹쳐도 거래는 1건.
  패턴별 표는 다중 소속(각 패턴의 사건)으로, '아무 상승 패턴' 합계와 대표 패턴(3봉 → 2봉 → 1봉 우선) 표는 1건 1칸으로 따로 낸다.
- 진입 ① 다음 5분봉 시가 · 국장 ② +20분 뒤 봉 시가. 상승 = 적중. 핵심 +5·+15분, 보조 +30분·MFE·MAE(15분·60분 창)·비용(0.05/0.10%) 차감·손익비.
- 기준선: **같은 시장 × 같은 시간대(장초반 60분 / 장중 / 마감 전 60분)** 의 모든 5분 시점 + 기존 E(5분 재돌파) 사건.
- 맥락: VWAP 대비 저가 깊이(위 / 0~0.1 / 0.1~0.3 / 0.3~0.5 / 0.5~1 / 1~2 / ≥2%) · VWAP 재진입(저가 < VWAP ≤ 종가) ·
  추세(**하락 반전** = 30분 하락 / **상승 눌림목** = 30분 상승 & 직전 30분 하락 / 그 밖) · 시간대 · 미장/국장 · 종목 분류.
- 지정 조합: 긴 아랫꼬리(아랫꼬리 ≥0.5) + VWAP 아래 반등(저가 < VWAP) · 샛별형/십자샛별형 + VWAP 아래 · 상승장악형 + VWAP 재진입.

## 3. 판정 (미리 정함)
- 워크포워드 2회(블록1→2, 블록1+2→3). 학습 선택: n≥30 · +15분 적중률 ≥ 같은 기간·시장·시간대 가중 기준선 +3%p · |z|≥2.
  검증 통과: n≥20 · 기준선 대비 +2%p 이상 · 비용 0.05% 차감 평균수익 > 기준선. 두 번 모두 통과해야 '검증 통과'.
- **연구 후보** = 전체 기간 +15분 상승 적중 ≥61% · n≥15. 검증 실패면 '미검증 연구 후보'. 어느 쪽도 매수 판정·등급에 쓰지 않는다.
- 화면 ⭐ 는 이 보고를 사용자가 확인하기 전까지 상승 패턴에 붙이지 않는다. 결과를 보고 기준·숫자를 바꾸지 않는다.
