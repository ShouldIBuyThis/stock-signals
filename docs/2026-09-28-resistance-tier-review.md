- 거리 = (res_short / 종가 - 1) × 100 / atr_pct. 저항 또는 ATR 결측은 통과시키지 않는다.
- 기존 추세 강한매수이면서 거리 >=2.5면 강한매수. 기존 추세 관심 이상이면서 >=1.5면 관심. 나머지는 중립. 기존 관심을 거리만으로 강매 승격하지 않는다.
- 승률 = +1% 초과 승 / (+1% 초과 승 + -1% 미만 패). ±1%는 승률 분모에서 제외한다. 평균수익에는 전체 표본을 포함한다.
- 표본은 종목×신호일이며 독립 거래 수가 아니다. 수익은 종가 기준이며 비용·손절·지정가 체결을 모사하지 않는다.
- 현재 유니버스에 대한 소급 백테스트다. frozen 2년 원장이 아니며 생존·선택 편향과 과거 실적 일정 누락 가능성이 남는다.
- 전후반 경계는 2025-09-24. 신호 성적 전반에서 보유 종료일이 경계를 넘는 표본은 제외했다. 시장 기준선(base) 전반은 endDate 미보유로 동일 경계 제거가 안 되어 채택 근거로 사용하지 않았다.
