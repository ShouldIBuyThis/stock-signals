# 9EMA 눌림 지정가 매수 — 모의 연구 사전 등록 (2026-11-10, 결과 전 커밋)

사용자 제안(2026-11-10): "장중 5분봉 9EMA 평균선까지 내려올 때 매수를 감지하면 괜찮을 것 같다 — 장중 시세로 모의 연구".
판정 산식(`idMtf`·state·E)·점수·등급·원장은 바꾸지 않는다. 계산은 화면 함수 `idMtf()`를 문자열로 추출해 봉마다 '그 시점까지 확정된 봉만' 넣어서만 한다.
참고(이미 있는 결과): ▲ 재돌파 뒤 9EMA 지정가는 미장 순 −0.047%·국장 −0.073%(+30분, docs/2026-11-10-rebreak-lag.md). 이번은 ▲와 무관한 일반 규칙이다.

## 규칙 (미리 고정)
- 무장: 확정 5분봉 종가 > 그 봉의 9EMA 이면 '무장', 지정가 = 그 봉의 9EMA. 다음 봉 하나 동안만 유효(봉마다 새 값으로 정정).
- 체결: 다음 봉 저가 ≤ 지정가 → 체결가 = min(그 봉 시가, 지정가). 체결 뒤에는 새로 '종가 > 9EMA'인 봉이 나와야 다시 무장(같은 눌림에서 거듭 사지 않음).
- 장 시작 30분 안에 시작한 봉의 체결은 제외(▲와 같은 기준). 결과 시간이 장 안에 없으면 미평가.
- 지연 D: 사용자는 봉 끝 + D분에 그 봉을 본다. 지정가·무장·필터는 '봉 끝 ≤ 주문 봉 시작 − D분'인 마지막 확정 봉 정보로만 정한다.
  D ∈ {0, 5, 20}. 미장 현실 ≈ 0~5 · 국장 현실 = 20(야후 실측).
- 필터(그 정보 봉 기준):
  - F0 없음 · F1 30분 추세 상승(`T.dir = up`) · F2 5분 9EMA > 20EMA ∧ 종가 > VWAP · F3 = F1 ∧ F2
- 성과: 체결가 기준 +5분(체결 봉 종가) · +15분 · +30분 종가. 비용 왕복 0.05%(기본)·0.10%. 상승 비율 · 평균 · 순수익 · 손익비 · MAE15.
- 민감도 '확실 체결': 저가가 지정가보다 0.05% 이상 아래로 내려간 봉만(지정가에 딱 닿기만 한 봉은 줄 서 있다가 못 살 수 있다).
- 주의: +5분(체결 봉 종가)은 '그 봉 안에서 지정가까지 내려왔다'는 사실 때문에 유리하게 나오기 쉽다 → 판단은 +15·+30분으로 한다.
- 기준선: 같은 시장의 15분 간격 아무 봉(다음 봉 시가).

## 검증 (결과를 보고 바꾸지 않음)
- 미장/국장 따로 · 앞/뒤 반쪽 · 3블록 워크포워드(1→2, 1+2→3): 학습 n≥30 · +15분 순 > 0 · 상승 비율 ≥ 같은 기간 기준선 +3%p → 검증 n≥15 같은 조건. **두 번 모두** 통과해야 '검증 통과'.
- 12칸(필터 4 × 지연 3) × 시장 2. 우연 통과 기대 개수를 같이 적는다.
- 통과해도 '연구 후보 · 매매 신호 아님'. 화면 반영은 사용자 확인 뒤.
