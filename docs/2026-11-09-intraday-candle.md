# 장중 5분봉 캔들 신호등 — 사전 등록 (2026-11-09, 결과 보기 전 커밋)

사용자 요청: 기존 '5분 재돌파' 옆에 캔들 형태 + 작은 신호등(🟢/🟡/🔴) + ⓘ 말풍선. **기존 판정(idMtf)·점수는 그대로**, 신호등은 별도 표시.
함수: `index.html` `idCandle(A, bar)` — 연구 도구는 이 함수를 문자열로 꺼내 쓴다(재구현 금지). 아직 화면에 연결하지 않았다.

## 1. 캔들 형태 (확정 5분봉, 비율 = 봉 전체 범위 대비)
몸통 b = |종−시|/범위 · 윗꼬리 u · 아랫꼬리 l. 큰 봉 = 범위 ≥ 직전 확정 5분봉 20개 범위 중앙값 × 1.5. 위에서부터 먼저 맞는 것:
1. 도지: b ≤ 0.1 (범위 0 포함)
2. 위아래 긴 꼬리: b ≤ 0.3 · u ≥ 0.3 · l ≥ 0.3
3. 긴 아랫꼬리: l ≥ 0.5 · u ≤ 0.2
4. 긴 윗꼬리: u ≥ 0.5 · l ≤ 0.2
5. 장대양봉: 양봉 · b ≥ 0.7 · 큰 봉
6. 장대음봉: 음봉 · b ≥ 0.7 · 큰 봉
7. 그 밖: 양봉 / 음봉

## 2. 신호등 (형태 + 위치·거래량·추세 — 캔들 하나로 단정하지 않음)
- 🟢 상승 우호: 형태 ∈ {장대양봉, 양봉, 긴 아랫꼬리} **그리고** 종가가 VWAP 아래가 아님 **그리고** 30분 추세 ≠ 하락 **그리고** 거래량 ≥ 직전 20봉 평균(정보 없으면 통과)
- 🔴 하락 경계: 장대음봉 · 또는 긴 윗꼬리이면서 (VWAP 아래 또는 오늘 저항(직전 확정 15분봉까지 고점)을 건드림) · 또는 음봉 · VWAP 아래 · 30분 하락
- 🟡 주의·불확실: 나머지
- 화면(나중): 미확정 봉 또는 장중 아닌 자료 → 신호등을 흐리게(강하게 표시 안 함).

## 3. 시험 설계
- 자료: 야후 5분봉 60일 · 사이트 종목(intraday-fetch.py). 5분 경계마다 확정 봉만 넣어 idMtf() → 마지막 확정 5분봉이 **5분 진입 조건(E)** 을 막 충족했으면 사건 1건.
  그 봉에 idCandle() 적용. 그중 상태가 🟢 5분 재돌파 확인(go)인 것도 따로 집계.
- 진입 = 다음 5분봉 시가. +5·+15·+30·+60분 종가 수익률, 적중(상승), MFE·MAE(60분 안). 장 마감으로 없는 시간대는 미평가.
- 기준 적중률: (a) E 사건 전체 (b) 같은 기간 모든 5분 판정 시점.
- 반쪽(앞 30일/뒤 30일), 미장/국장. 표본 등급 §5-1.
- **유용 판정(미리 정함)**: 🟢가 E 전체보다 +15·+30분 적중률이 3%p 이상 높고 🔴가 3%p 이상 낮으며, 두 반쪽에서 방향이 같고 각 n ≥ 50.
  못 미치면 화면에는 "형태 설명"만 두고 신호등은 '참고'로 약하게 — 결과를 보고 숫자를 바꾸지 않는다.

## 4. 추가(실행 전): 구조적 한계와 보조 분석
- 5분 진입 조건(E)은 캔들 조건(양봉 몸통 ≥50% 또는 긴 아랫꼬리)을 포함하므로 **재돌파 봉 자체는 🔴가 나올 수 없다**.
- 그래서 화면에서 실제로 신호등이 붙을 대상 — **E 충족이 표시되는 동안(재돌파 뒤 1·2번째 확정 봉)의 최신 확정 봉** — 을 따로 집계한다([5]). 같은 유용 판정 기준을 적용한다.
