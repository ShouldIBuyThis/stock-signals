## 판정
- **세 곳 모두 자동 수집 허용이 확인되지 않았다 → 수집하지 않는다.**
  - signals.kr은 실시간 경로(`/live/`)와 재판매 목적 봇을 robots에서 막았고, 원천이 증권사 시세라 재이용 조건이 그쪽 약관에 묶인다.
  - 지표담은 데이터센터 접근 자체를 404로 돌려보낸다.
  - 국장지도는 `/api/`를 막았고 약관 본문을 확인하지 못했다.
- 화면 링크(국장 장중 화면 한 줄)는 수치를 가져오지 않으므로 그대로 둔다.

## 합법적인 무료 대안(우선순위)
1. **KRX 정보데이터시스템 투자자별 거래실적(일별 · 시장/개별종목 · 금융투자·보험·투신·사모·은행·기타금융·연기금·외국인 등)** — 사용자가 화면에서 직접 CSV로 내려받아 저장소에 넣으면 내부 연구(1·3·5거래일)는 바로 가능. 공개 화면에 원자료 재게시는 하지 않는다. 자동 내려받기는 KRX 이용약관 확인 뒤에만.
2. **KRX Open API(무료 · 인증키)** — 공식 경로. 투자자별 자료 포함 여부를 신청 화면에서 확인 필요.
3. **증권사 Open API(예: 한국투자 · 본인 계좌 키)** — 장중 투자자별 가집계 제공. 본인 연구용 수집은 가능할 수 있으나 제3자 제공·재게시는 약관상 어려울 가능성이 큼 → 연구 결과(통계)만 쓰고 원자료는 비공개.
4. **운영자 허락** — signals.kr은 연락처(contact@signals.kr)를 공개하고 있다. 연구용 자동 수집 허락을 받으면 그 범위 안에서만.

## 장중 15·30·60분 연구의 현실
- 무료·합법 경로 중 **과거 장중 수급 이력**을 주는 곳은 확인되지 않았다 → 장중 연구는 허락된 경로로 오늘부터 쌓아야 하고, 서로 다른 날 20일 이상(약 4주) 뒤에야 판정 가능.
- 1·3·5거래일 연구는 KRX 일별 자료로 과거 수년치를 바로 쓸 수 있다 → **먼저 이것부터**.
