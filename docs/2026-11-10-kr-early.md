# 국장 5분봉 조기 상승·하락 조짐 + 하락 판정 직후 반등 — 사전 등록 (2026-11-10, 결과 전 커밋)

사용자 지시(2026-11-10): 국장 장중 상승·하락 판정이 둘 다 늦다. 야후 국장 시세가 이미 약 20분 늦으므로 15·30분봉 확정을

11/10 229200.KS를 시간순으로 재생해 얼마나 빨라지는지, 하락 판정 직후 반등이 우연인지 구조적인지 확인한다.

**바꾸지 않는 것**: 일봉 점수·등급·원장 · ▲·⭐·⚠️ 연구 마커 · 기존 15·30분 판정 `idMtf()`(그대로 추출해서 쓴다). 미장은 대상 아님.

## 재생 방식 (미래 참조 금지)
- 각 5분봉이 끝난 순간 τ마다 `idMtf(…, τ)`를 그 시각까지의 봉만으로 다시 계산 → 기존 판정(state)과 확정 5분봉(EMA9·EMA20·VWAP)을 얻는다.
  스토캐스틱 골든크로스·과매도 탈출·반등 캔들은 `idUpEvidence()` 그대로.
- **발생 시각** = 봉 끝 τ. **화면 확인 가능 시각** = τ + 20분(국장 야후 지연 실측 20.0~21.1분). 둘을 항상 따로 적는다.
- 진입·관측 가격(D20) = τ + 20분 이후 첫 5분봉 시가. 참고로 D0(지연 없음)도 적는다.

## 조기 신호 원자 (확정 5분봉 L · 직전 P · 그 전 Q · atr5 = 5분봉 ATR14)
| 계열 | 상승 | 하락 |
|---|---|---|
| EMA20 | U1 회복: Q·P 종가 ≤ EMA20 → L 종가 > EMA20 · U2 첫 지지 반등: P·Q 종가 > EMA20, L 저가 ≤ EMA20 + 0.1·atr5, L 종가 > EMA20, 양봉, P는 닿지 않음 | D1 이탈: Q·P 종가 ≥ EMA20 → L 종가 < EMA20 · D2 지지 실패: P 종가 ≥ EMA20 → L 종가 < EMA20, 직전 6봉 안에 EMA20에 닿고 버틴 봉 있음 |
| EMA9 | U3 재돌파: P 종가 ≤ EMA9 → L 종가 > EMA9, EMA9 상승 | D3 이탈: P 종가 ≥ EMA9 → L 종가 < EMA9, EMA9 하락 |
| VWAP | U4 회복: P ≤ VWAP → L > VWAP | D4 이탈: P ≥ VWAP → L < VWAP |
| 구조 | U5 L 종가 > P 고가 ∧ L 저가 > P 저가 | D5 L 종가 < P 저가 ∧ L 고가 < P 고가 |
| 스토캐스틱 | U6 골든크로스 또는 과매도 탈출(idUpEvidence S1·S2) | D7 데드크로스(높은 쪽 > 50) 또는 과매수 이탈(80 아래로) — 같은 14·3·3 |
| 캔들·거래량 | U7 반등 캔들(C1~C4) ∧ 거래량 직전 20봉 평균 1.5배↑ | D6 3연속 음봉 ∧ 거래량 1.5배↑ |
- U1f·D1f = 그날 첫 U1·D1. 오늘 3번째 봉부터(09:15 끝) 계산.

## 조합 칸 (고정 · 방향별 13칸)
- 원자 단독 7개 + U1f/D1f
- K1 = EMA20 원자 발생 ∧ 다른 계열 1개 이상이 최근 3봉 안에 발생
- K2 = EMA20 원자 발생 ∧ 다른 계열 2개 이상
- K3 = 최근 3봉 안에 서로 다른 계열 3개 이상(이번 봉에 하나 이상 새로)
- K4 = EMA20 원자(최근 3봉) ∧ 같은 방향 구조(U5/D5, 최근 3봉) ∧ VWAP 같은 쪽(상승: 종가 > VWAP · 하락: <)
- 같은 칸은 같은 종목·날 30분(6봉) 안에 다시 세지 않는다.

## 평가
- 상승: +15·30·60분 · 다음 거래일 종가의 상승 비율, 평균 순수익(비용 = ETF 왕복 0.03% · 주식 0.21%, 매수 +1호가 · 매도 −1호가).
- 하락: 같은 구간의 하락 비율 · 평균 수익률(보유자가 피한 움직임 · 공매도 아님).
- 거짓 신호율: 관측 뒤 30분 안에 종가가 신호 봉 저가 아래(상승) / 고가 위(하락).
- 취소율: 신호 뒤 30분 안에 반대 방향 EMA20 원자 또는 반대 K1 발생(번갈아 뜸).
- 기존 판정보다 빠른 시간: 신호 시점에 기존 판정이 이미 같은 방향(상승 = up·go·wait·pull / 하락 = down)인 비율, 그날 나중에 나온 비율과 앞선 분(중앙값), 그날 안 나온 비율.
- 무작위 대조: 같은 종목·날 09:30 이후 15분 간격 봉. **같은 기존 판정 상태**(상승계·하락·탐색·보류)별로 나눠, 신호의 상태 분포로 가중한 무작위와 비교.
- 독립 표본: 서로 다른 날 · 종목 수, 날짜별 평균 적중률. 워크포워드: 날짜 3블록, 1→2 · 1+2→3.

## 표시 후보 판정 (결과 보고 바꾸지 않음)
D20 · +30분 기준, 아래를 **모두** 만족하는 칸만:
1. 적중률(상승 비율/하락 비율) ≥ 상태 맞춘 무작위 + 5%p, 평균(순수익/수익률)도 무작위보다 유리
2. 거짓 신호율 < 무작위의 같은 정의 비율
3. 워크포워드 두 번 모두 1·2 유지
4. n ≥ 100 · 서로 다른 날 ≥ 20 · 종목 ≥ 10
- 통과 칸 중 기존 판정보다 가장 많이 앞선 칸 하나를 방향별로 쓴다. 통과해도 매수·매도 신호가 아니라 '관측된 조짐(미확증)'으로만 표시한다.
- 통과 칸이 없는 방향은 조짐을 띄우지 않는다.

## 하락 판정 직후 반등 (B)
- 사건: 기존 판정이 상승계·탐색 → down으로 바뀐 봉(보류→down은 개장 직후라 따로).
- 사건마다: 발생 시각·가격 / 확인 가능 시각(+20분)·가격 / +5·15·30·60분·다음 거래일 수익률 / 관측 뒤 60분 추가 하락폭(최저 저가) · 그 뒤 반등폭 /
  장중 저점(그때까지) 이후 경과 분 / 그때까지 하락폭 중 이미 진행된 비율 / 그날 최종 저점이 판정보다 앞섰는지.
- 대조: 같은 날 하락 상태 무작위 · 전체 무작위 · 대형주는 같은 시간 지수 ETF(코스피 → 069500, 코스닥 → 229200) 수익률을 뺀 초과 수익.
- 판정 시점 특징별(탐색): EMA9 위로 이미 회복 · %K < 20 · 최근 3봉 긴 아랫꼬리(≥ 범위 50%)+거래량 1.5배 · 저점 상승(직전 6봉 최저 위) · 저점 뒤 3봉 이상 경과.
- (결과 전 추가 · 사용자 확인 사항 3) 판정 순간 5분봉이 이미 저점 회복을 보였는지: '직전 20분 조기 상승 원자 있음'을 특징에 더하고, 229200 재생에서는 사건마다 그날 최종 저점 봉과의 앞뒤 · 각 특징 · 직전 20분 상승 원자 목록을 적는다.
- 국장 야후 15:00~15:30 5분봉은 없다 → 채우지 않는다. 그 구간에 걸리는 +분 결과는 '없음'으로 빼고, 14:40 이후 신호처럼 확인 가능 시각에 봉이 없으면 '장 마감으로 관측 불가'로 따로 센다. 다음 거래일 결과만 공식 종가(15:30)를 쓴다.
- 같은 분석을 하락 조기 칸(D1·K1)에도. 번갈아 뜨는 횟수: 기존(상승계 ↔ down 전환 / 종목·일), 조기(반대 방향 30분 안).
- '하락 판정 직후 반등이 평소보다 잦다' = 관측 뒤 +30분 상승 비율이 같은 하락 상태 무작위 + 5%p 이상 ∧ 지수 대비 초과도 양(+) ∧ 두 워크포워드 블록 같은 방향.
  그래도 매수 신호로 바꾸지 않는다 — 화면은 '30분봉 하락 · 5분봉 반등 시도'처럼 두 시간대를 나눠 보여 주는 것까지만 검토.
