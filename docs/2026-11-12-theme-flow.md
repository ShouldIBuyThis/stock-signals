## 0. 자료의 성격 — 탐색 연구
- 종목 일봉: 야후 수정주가(auto_adjust) · 2015-09~. 기존 E/T/X 묶음은 이미 여러 번 봤다 → **미사용 독립 검증으로 부르지 않는다.**
- 테마 변수는 '지금 관심종목' 구성으로만 만들 수 있다(과거 구성 복원 불가) → **현재 관심종목 고정 유니버스 소급 분석 · 생존 편향 있음**.
- 4그룹도 **현재 구성 종목 소급**(편출·상장폐지 종목 없음)이다. 실제 과거 구성 기준과 구분해 표기한다.
- 따라서 이번 결과는 전부 **탐색**이다. '탐색 통과'는 전진 검증(앞으로 쌓이는 원장) 후보라는 뜻이지 검증 통과가 아니다.
- 내부 일관성 확인: 기간 반쪽(전반/후반) · 시장 국면 · 이웃 문턱(고원). 미래 값으로 조건을 만들지 않는다(롤링·과거 이동만).

## 1. 공통 정의
- 52주 고가/저가 = 그날까지 252봉의 최고 High / 최저 Low. **252봉 미만은 판정에서 제외**(분모에도 안 넣음).
- 신고가권 = 종가 ≥ 52주 고가 × 0.99 · 신저가권 = 종가 ≤ 52주 저가 × 1.01 (사이트 기존 정의와 같음).
- 그날 분석 가능 종목 수 n = 252봉 이상 ∧ 그날 종가가 있는 종목 수. 신고가 비율 hr = nh/n · 신저가 비율 lr = nl/n · 순신고가 net = hr − lr.
- 5일 평균 hr5·lr5·net5 · 변화 Δk = net5(d) − net5(d−k) (k = 3·5·10).
- 미국장과 한국장은 섞지 않는다. 레버리지 상품(SOXL·GDXU·NAIL·UYG·DUSL·FNGU·BULZ)은 기초 자산 중복 노출이라 테마 집계와 사건에서 뺀다.
- **최소 표본**: 테마는 그날 n ≥ 4일 때만 비율·비교·연구 대상(미만은 '자료 부족'). 4그룹은 n이 현재 구성 수의 50% 이상일 때만.
- 시장 국면: 상승 = QQQ 종가 > 200일선 ∧ 60일 수익 > +5% · 하락 = 종가 < 200일선 · 횡보 = 나머지.

## 2. 테마 상태 (종목 연구에서는 **자기 종목을 뺀** 테마 값을 쓴다 — 기계적 겹침 방지)
- 약화 T_WEAK: Δ5 ≤ −5%p ∧ hr5(d−5) > 0.
- 확산 T_SPREAD: Δ5 ≥ +5%p ∧ 최근 5일 신고가권에 든 서로 다른 종목 ≥ 2 ∧ lr5(d) ≤ lr5(d−5).
- 소수 집중 T_NARROW: 자기 종목은 신고가권인데 테마의 다른 종목은 최근 5일 신고가권 0개.
- 화면 라벨: 확산 / 약화 / 혼조(그 밖) / 자료 부족(n<4). 이웃 문턱 3%p·8%p는 고원 확인용(고르지 않는다).

## 3. 개별 종목 신호 묶음 (그날 값만 · pattern_flags 정의 재사용)
- 기본 교집합 I = 종가가 52주 고가의 5% 안 ∧ 볼밴 %B(종가) ≥ 0.8.
- **A = I ∧ 같은 날 위험 캔들**(석별형·유성형·교수형·팽이/도지·윗꼬리 50%↑·장대음봉 중 하나).
- A+M = A ∧ 모멘텀 약화(최근 3거래일 안 RSI 약세 다이버전스 ∨ MACD 3일 연속 감소 ∨ 스토캐스틱 과열권 데드).
- **A+T = A ∧ T_WEAK** · **A+T+MK = A ∧ T_WEAK ∧ 시장 확인**.
- 시장 확인 MK = 관심종목 미국 전체(레버리지 제외)의 Δ5 < 0. 변형 MK4(4그룹 자료가 있을 때만 병기) = §6의 R_DEF ∨ H_NDX ∨ H_SP ∨ ALL_DN.
- 과열 묶음 O = 사이트 🟠 코드(O_RSI ∨ O_EXT ∨ O_TURN ∨ O_VOLSTALL) · O+T · O+T+MK (같은 방식).
- 다이버전스 DV = 종가가 52주 고가의 5% 안 ∧ 5일 수익 > 0 ∧ T_WEAK(캔들 무관) · DV+ = DV ∧ (윗꼬리 50%↑ ∨ 최근 3일 RSI 약세 다이버전스 ∨ 거래량 5일 평균 < 20일 평균).
- 상승 지속 후보 OH = 신고가권 ∧ RSI ≥ 70 → OH ∧ T_SPREAD 대 OH ∧ ¬T_SPREAD.
- 사건 = 같은 종목·같은 묶음 5거래일 안 재발생 제외. 같은 날 여러 종목은 날짜 가중(그날 사건 수로 나눔).

## 4. 성과 (평가 전용) — 핵심 기간 1·3·5·7거래일
1. n일 뒤 하락 비율(종가 −1% 미만 / ±1% 밖) · 평균 수익 (신호일 종가 기준 · 다음 날 시가 기준 병기)
2. 같은 기간 추가 상승 비율(+1% 초과 / ±1% 밖)
3. 7일 안 최대 추가 상승폭(고가)·최대 하락폭(저가)
4. 단기 고점까지 남은 거래일 = 신호일 포함 10거래일 안 종가 최고일까지의 거리(중앙값 · 0~1일 비율)
5. 일부익절 뒤 놓친 비율 = 다음 날 시가(익절가) 대비 7일 안 종가가 +5% 이상 오른 비율
6. 비교: 부분집합 대 나머지(A+T 대 A∖T 등) · A 대 기본 교집합 I(캔들 없음)
- **1/3 일부익절 전략**: 신호 다음 거래일 시가에 1/3 매도(매도분에 비용·슬리피지 0.15%) + 2/3 보유 대 전량 보유 — 3·5·7일 수익 차이 · 기간 중 최대 낙폭 평균 · 익절이 유리했던 비율.
- 통계: 5일 하락 비율 차이의 날짜 군집 부트스트랩 90% 신뢰구간(2,000회 · 시드 고정) · 오경보율 = 5일 뒤 +1% 넘게 오른 비율.
- **탐색 통과 기준(전부)**: 사건 50+ ∧ 서로 다른 날 30+ ∧ 5일 하락 비율이 비교 대상보다 +5%p 이상 ∧ 3·7일도 같은 부호 ∧ 5일 평균 수익이 더 낮음 ∧
  신뢰구간 하한 > 0 ∧ 전반·후반 모두 같은 부호. 사건 50 미만은 승률이 높아도 '표본 부족'. (OH 확산은 방향을 뒤집어 '상승 비율 +5%p'.)
- 문턱을 결과에 맞춰 조이거나 드문 조합을 골라 승률을 올리지 않는다. 통과하지 못한 조건도 모두 표에 남긴다.
- 분해 보고: 시장 국면 3종 · 테마 규모(n 4~5 / 6+) · 소수 집중 여부.

## 5. 테마 약세·반등 (테마 단위 · n ≥ 4)
- 신저가 급증 LOWSURGE: lr5(d) − lr5(d−5) ≥ +10%p. 신저가 많음(비교용) LOWMANY: lr5 ≥ 20%.
- 신저가 증가 멈춤 LOWSTOP: 직전 10일 lr5 최고 ≥ 10% ∧ lr5(d) ≤ 그 최고 − 5%p (처음 성립한 날 · 10일 쿨다운).
- 신고가 재등장 HIGHBACK: hr5(d) > 0 ∧ 직전 20일 hr5 모두 0 ∧ 직전 20일 lr5 최고 ≥ 10%.
- 성과: 그 테마 종목(레버리지 제외) 동일가중 평균의 1·3·5·7일 수익 · 상승 비율(+1% 초과) 대 모든 테마·날. 신저가가 많다는 것만으로 바닥이라 하지 않는다 —
  LOWMANY 단독 성적을 같이 보고한다. 통과 기준은 §4와 같은 구조(상승 비율 +5%p).

## 6. 4그룹 통합 비교 (S&P500 · 나스닥100 · 경기방어 · 배당)
- 구성(스냅샷 날짜를 자료에 기록 · **현재 구성 종목 소급**):
  - S&P500 = 위키백과 'List of S&P 500 companies' 현재 구성 종목.
  - 나스닥100 = 위키백과 'Nasdaq-100' 현재 구성 종목(나스닥 종합이 아니라 **나스닥100**으로 표기).
  - 경기방어 = S&P500 구성 종목 중 GICS 필수소비재(Consumer Staples) 전체 + 유틸리티(Utilities) 전체 +
    헬스케어 중 제약(Pharmaceuticals)·건강보험(Managed Health Care)·의약품 유통(Health Care Distributors).
  - 배당 = SCHD 편입 종목(`data/groups/schd-holdings.csv` — 출처·기준일을 파일에 적는다). **파일이 없으면 배당 그룹은 '구성 자료 없음'으로 두고
    ETF(SCHD) 한 종목의 신고가 여부로 대신하지 않는다.** 배당 그룹이 필요한 상태(R_DIV·DEF_ONLY의 배당 조건)는 그때까지 보류.
  - 그룹 간 종목 중복은 그대로 두되 중복 수를 보고한다(경기방어 ⊂ S&P500 · 나스닥100 ∩ S&P500 등).
- 지표: 그룹별 hr·lr·net(= (nh − nl)/n × 100) · 5일 평균 · Δ5. 지수 위치: QQQ·SPY 종가의 52주 고가 대비.
- 상태(날짜 단위 · 문턱 2%p 고정 · 이웃 1·3%p는 고원 확인):
  - NDX_LEAD: Δ5(NDX) ≥ +2%p ∧ Δ5(NDX) − Δ5(SP) ≥ +2%p · SP_LEAD: 반대.
  - R_DEF(성장 감소 + 방어 증가): Δ5(NDX) ≤ −2%p ∧ Δ5(DEF) ≥ +2%p · R_DIV: 같은 식에 배당.
  - H_NDX(지수는 고점 유지 · 내부 감소): QQQ가 52주 고가의 2% 안 ∧ hr5(NDX)(d) − hr5(NDX)(d−10) ≤ −3%p · H_SP: SPY·S&P500으로 같은 식.
  - DEF_ONLY: hr5 10일 변화가 경기방어(·배당) ≥ +2%p ∧ S&P500·나스닥100은 ≤ 0.
  - ALL_UP: 네(자료 있는) 그룹 모두 net5 > 0 ∧ Δ5 > 0 · ALL_DN: 모두 net5 < 0 ∧ Δ5 < 0.
- 성과: QQQ·SPY의 3·5·7일(1일 병기) 수익 · 하락 비율(±1% 보합 제외) 대 모든 날 · 시장 국면별. 사건 = 상태가 처음 켜진 날(5거래일 쿨다운),
  모든 상태일 성적은 10일 블록 부트스트랩 90% 신뢰구간과 함께 참고로.
- 탐색 통과: 처음 켜진 날 30+ ∧ 5일 하락 비율이 모든 날과 5%p 이상 차이 ∧ 3·7일 같은 부호 ∧ 신뢰구간이 0을 포함하지 않음 ∧ 전·후반 같은 부호.
- 일부익절 연결: §3의 MK4 변형으로만(별도 문턱 추가 없음).
