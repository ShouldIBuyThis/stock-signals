# 장중 '큰 흐름' 판정 2년 검증(60분봉 근사) — 사전 등록 (2026-11-10, 결과 전 커밋)

사용자 지적: 과거 60일(8/18~11/9)은 약세장이다(QQQ 20·60일선 아래, 20일 −8.9%) → 2년은 봐야 한다.
제약: 야후 5분·15분·30분봉은 최근 60일만 준다. 2년(730일)을 주는 가장 짧은 봉은 60분봉이다.
→ 화면 판정(idMtf: 30분 추세 · 15분 지지 · 5분 재돌파)을 **그대로 2년 시험할 수는 없다.** 여기서는 그중 '30분 추세' 규칙을
**60분봉에 같은 식으로 적용한 근사**만 시험한다(15분 지지·5분 재돌파는 시험 불가 — 결과에 같이 적는다).
화면·판정·점수 변경 없음.

## 규칙 (idMtf의 T 규칙을 60분봉에 그대로)
- 확정 60분봉 x · EMA9/EMA20(60분봉 종가 · 날을 넘어 이어짐) · VWAP(그날 60분봉 누적, 대표가 (H+L+C)/3 × 거래량)
- 상승 = 종가 > VWAP ∧ EMA9 > EMA20 ∧ EMA20 ≥ 3봉 전 EMA20 · 하락 = 종가 < VWAP ∧ EMA9 < EMA20 · 그 외 중립. VWAP 계산 불가(거래량 0)면 VWAP 조건 생략(화면과 같음).
- 판정은 그 봉이 끝난 시각의 정보만. 결과는 **다음 봉 시가 진입** → +1봉 · +2봉 종가 · 그날 종가 · 다음 거래일 종가.
  국장은 야후 20분 지연이 있으므로 '다음 봉 시가'(최소 0~60분 뒤)도 함께 보되, 실제로 볼 수 있었던 시각과 정확히 맞추지는 못한다(근사).
- 대상: 사이트 관심종목(미장·국장 모두). 비용은 적지 않고 방향만 본다(장중 비용 문제는 docs/2026-11-10-kr-early.md).

## 국면
- 미장: QQQ 일봉 종가 vs 200일선(위 = 상승장 / 아래 = 하락장) · 국장: ^KS11 같은 방식. 전날 종가 기준(그날 정보 미사용).
- 2년을 6개월 4블록으로도 나눈다.

## 판정 (결과 보고 바꾸지 않음)
- '상승' 판정이 같은 국면·같은 시장 무작위(모든 확정 봉)보다 +1봉·+2봉 상승 비율이 높고, **상승장·하락장 양쪽**과 **4블록 중 3블록 이상**에서 같은 방향이면 '방향 정보 있음'.
- '하락' 판정도 같은 기준(하락 비율).
- 차이가 2%p 미만이면 크기 면에서 의미 없음으로 적는다.
- 5분 재돌파(🟢)·눌림·⭐/⚠️ 마커는 이 자료로 시험할 수 없다 — 정확한 2년 시험에는 다른 분봉 자료원이 필요하다(미장: 무료 API 키 방식 업체 · 국장: 무료 공식 경로 미확인).
