# 🏆 황금신호 × 테마 52주 흐름 — 국면별 교집합 탐색 (사전 등록 · 2026-11-12 · 결과 전)

사용자 지시: 국면별 황금신호 승률을 80% 이상으로 높일 조합 탐색. 황금신호 선정 기준·매수 산식은 바꾸지 않는다(연구만).
도구: `tools/gold-3y-lab.js`(GTHEME 모드 · 화면 함수 그대로) + `tools/gold-theme-analysis.js`(집계).

## 1. 자료·기간
- 10년 백필(관심종목 소급 · 생존 편향). 황금 = 화면 기준 일봉 쪽(미장: 일봉 등급 ∩ 상승 캔들 / 국장: 일봉 등급 ∩ (상승 캔들 또는 %B≤10)) · 장중 ▲ 조건은 1년 이상에 못 건다.
- 국면(그날까지): 미장 QQQ · 국장 KODEX200 — 200일선 위·60일 수익 + = 상승 / 아래·− = 하락 / 그 밖 횡보.
- 기간 셋: **최근 1년** · **최근 3년(탐색 = 조합을 고르는 기간)** · **그 이전(약 2017~2023 · 재현 확인)**. 황금 규칙 자체를 3년 자료로 정했으므로 이전 기간도 '완전 독립'은 아니다 — '재현 확인'이라고만 부른다.

## 2. 결과(신호 다음 거래일 시가 진입)
- N = 3·5·7·10거래일 뒤 종가 수익 · N일 안 종가로 한 번이라도 +1/+2/+3% 도달(먼저 내려가도 적중) · +1% 도달 전 최대 낙폭 · 평균 수익 · 최악 5일 수익.
- **주요 목표: 5일 안 +1% 도달률 80%** · 5일 최종 수익을 같이 본다.

## 3. 테마 조건(그날까지의 원장 값만 · 분석 종목 4개 이상 · 레버리지 제외)
테마 = 종목의 화면 테마(category). 지표: hr(신고가권 = 52주 고가 −1% 안 비율) · lr(신저가권 = 52주 저가 +1% 안) · net = hr − lr · 5일 평균 hr5·lr5·net5 · ab20(20일선 위 비율).
**자기 종목 포함**과 **자기 종목 제외(LOO)** 두 가지로 따로 계산한다.
- T_HRUP: hr5 − hr5(5일 전) > 0 · T_LRDN: lr5(5일 전) > 0 ∧ lr5 감소
- T_NET3 / T_NET5 / T_NET10: net5 − net5(3·5·10일 전) > 0
- T_LOWSTOP: 직전 10일 lr5 최고 ≥ 10% ∧ lr5 ≤ 최고 − 5%p · T_HIGHBACK: hr5 > 0 ∧ 직전 20일 hr5 모두 0 ∧ 직전 20일 lr5 최고 ≥ 10%
- T_SPREAD: hr5 5일 변화 ≥ +5%p ∧ 최근 5일 신고가권 서로 다른 종목 ≥ 2 ∧ lr5 ≤ 5일 전 · T_AB20: ab20 − ab20(5일 전) > 0
- 4그룹(`backtest/group-breadth.json`): G_NDX / G_SP / G_DEF = 그룹 순신고가 5일 평균의 5일 변화 > 0(일별 수는 2023-09~만) · G_ALLUP = 전 그룹 확산 상태(2016~).
- 조합 = 위 조건 1개 또는 2개 교집합(같은 LOO 방식끼리). 국면(상승·횡보·하락) × 시장(미장·국장)마다 따로 탐색한다.

## 4. 표본·판정
- 사건 = 같은 종목 5거래일 안 재발생 제외. 5~9건 극소표본 · 10~29건 소표본 연구 후보 · 30건↑ 추가 검증 후보. 적중·실패 건수 · 독립 날짜 수 · 최다 종목·테마 비중을 같이 적는다.
- 대조: 같은 국면 모든 종목·날(평소) · 같은 국면 황금 전체 · 같은 국면 황금 중 그 조건이 아닌 것.
- **'80% 조합'(탐색 3년에서 5일 +1% ≥ 80%)** 과 **'재현된 추가 효과'**(이전 기간에서도 사건 10↑ ∧ 5일 +1% ≥ 80% ∧ 같은 국면 황금 대비 +5%p↑)를 따로 센다.
  탐색한 조합 수와 우연 기대(이항 꼬리)를 적는다. 표본이 작아 80%가 된 조합을 '개선'이라 부르지 않는다.
- 결과로 문턱·조건을 바꾸지 않는다.
