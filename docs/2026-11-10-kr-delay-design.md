# 국장 20분 지연 보정 연구 — 설계 (2026-11-10, 실행 전 · 사용자 확인 뒤 실행)

사용자 지시(2026-11-10): 지연된 자료로 현재 시세를 아는 척하지 않는다. 실제로 확인할 수 있는 시점의 정보만 쓴다.
검증된 예측력이 없으면 매수 추천으로 표시하지 않는다. 국장 시세 출처·기존 매매 산식은 바꾸지 않는다.
앞서 등록한 `docs/2026-11-10-rebreak-lag.md`(▲ 지연·과열·소진·재눌림)의 확장이다. 그 문서의 정의는 그대로 둔다.

## 0. 자료 고정
- 보존 스냅샷 1개만 쓴다(`intraday-snapshot.yml` run id · 수집 시각 · sha256을 결과에 적는다). 야후를 다시 부르지 않는다.
- 계산은 화면 함수(`idMtf`·`idCandleFeat`·`idStarEvents`)를 문자열로 추출해서만 한다.

## 1. 시간 모형 (아는 것과 모르는 것을 분리)
- τ = 신호 봉이 끝나는 시각. 화면이 이 봉을 '확정'으로 그릴 수 있는 가장 이른 시각.
- 지연 L = 제공처 지연 + 캐시(90초) + 조회 간격. 실측: 국장 야후 약 20분, 미장 약 1분.
- **사용자가 τ+L에 아는 것 = τ까지의 봉뿐.** τ~τ+L 사이 봉은 판단·필터에 쓰지 않는다.
- **사용자가 실제로 체결하는 가격 = τ+L 이후 첫 5분봉 시가**(그 시점의 진짜 가격 — 사용자는 못 보고 주문한다).
- L ∈ {0, 5, 10, 20, 30}분. 국장 현실 = 20, 미장 현실 = 0~5. 전부 적되 시장별 '현실 L'을 굵게.

## 2. 신호 (모두 τ 시점 확정 봉만으로)
- S1 ▲ 5분 재돌파(E 충족 봉). 부분집합: 그 시각 종합 상태 🟢.
- S2 VWAP 회복: `docs/2026-11-09-vwap-dip.md` §3 M3(눌림 깊이 0.5·1.0 ATR에 닿은 뒤 첫 종가 ≥ VWAP) — 정의 재사용, 새로 만들지 않는다.
- S3 캔들 연구 후보 4종(⭐ 장대양봉+하락 주의 · ⭐ 역망치형+진입 대기 · ⚠️ 잠자리 도지+하락 주의 · ⚠️ 석별형+하락 주의) — `idStarEvents` 사건. ⚠️는 하락이 적중.

## 3. 성과
- A(신호 시점): 진입 = τ 뒤 첫 봉 시가(L=0). B(지연 확인): 진입 = τ+L 뒤 첫 봉 시가.
- +5·+15분(핵심) · +30분(보조): 방향 적중률, 평균, 손익비, 비용 차감 순수익.
- 비용·슬리피지: 왕복 0.05%(기본) · 0.10% · 0.20%(민감도). 국장 개별주 거래세는 미반영(현재 국장 종목은 ETF 위주)이라고 적는다.
- '지연 손실' = B − A (같은 사건끼리 짝지어 차이). τ~τ+L 사이에 이미 지나간 움직임(= 놓친 수익 또는 피한 손실)도 따로 적는다.
- 기준선: 같은 시장의 15분 간격 아무 시점(다음 봉 시가).

## 4. 나눠 보기 (전부 τ 시점 정보로만 분류 · 구간 미리 고정)
1. **첫 재돌파 vs 반복**: 그 종목 그날의 n번째 ▲ (1번째 / 2번째 이상). 직전 ▲부터 30분 이내 재발 여부.
2. **과열**: (종가 − VWAP)/15분 ATR, (종가 − 9EMA)/ATR — <0.5 · 0.5~1.5 · ≥1.5.
3. **이미 오른 폭**: (종가 − 직전 30분 저가)/ATR — <1 · 1~2 · ≥2.
4. **저항까지 남은 거리**: (R − 종가)/ATR — 저항 위(돌파) · <0.5 · ≥0.5 · 저항 없음.
5. **시간대**: 장 시작 60분 / 장중 / 마감 전 60분. **30분 추세**: 상승·중립·하락.
- 사후 설명용(필터로 쓰지 않음): '고점 형성' = 60분 최고가가 첫 20분 안 ∧ 60분 종가 < L=0 진입가. '여력 남음' = 그 반대.
  두 무리의 τ 시점 특징(위 1~5) 분포를 나란히 적는다. **이 라벨 자체는 미래 정보라 화면·필터에 쓰지 않는다.**

## 5. 검증 규칙 (결과를 보고 바꾸지 않음)
- 워크포워드: 날짜순 3블록, 1차 블록1→2, 2차 블록1+2→3.
  학습 선택: n≥30 · 현실 L에서 +15분 순수익(0.05%) > 0 · 적중률 ≥ 같은 기간 기준선 +3%p.
  검증 통과: n≥15 · 순수익 > 0 · 적중률 ≥ 기준선 +3%p. **두 번 모두** 통과해야 '검증 통과'.
- 반쪽(앞/뒤 30일) 방향 일치, 이웃 구간도 같은 방향(§3 고원), 표본 등급(§5-1).
- 본 칸 수와 '기준선만으로 우연히 통과할 기대 개수'를 같이 적는다.
- 미장/국장 따로. 국장은 종목 6~8개(ETF)뿐이라 표본 등급이 '방향만'에 그칠 가능성이 높다 — 그러면 그렇게 적고 결론을 내지 않는다.
  미장 자료에 L=20을 적용한 결과는 '지연의 일반 효과' 참고로만 쓰고 국장 결론으로 옮기지 않는다.

## 6. 결과가 나오면 화면에 할 수 있는 일 (미리 정함)
- 현실 L에서 순수익 ≤ 0 이거나 기준선과 차이가 없으면: 그 신호는 '지난 사건 · 추격 주의'로만 표시(이미 적용한 ▲ 경과 표시 유지). 매수 후보 문구 금지.
- 어떤 구간이 검증을 통과해도 '연구 후보 · 매매 신호 아님'. 매수 추천으로 격상하지 않는다. 문구 변경은 사용자 확인 뒤.
- 종합 점수·등급·`evaluate()`·`idMtf` 판정은 어떤 경우에도 바꾸지 않는다.
