# 🔴 고점판독 — 20거래일 뒤 종가 하락 확률 기준 연구 (사전 등록 · 2026-11-12 · 결과 전)

사용자 지시: "신호일 종가에 매수한 뒤 20거래일 후 종가가 낮아질 확률 — 앞으로 고점판독 연구는 그 기준으로만 평가 · 일부익절과 구분".
- **고점판독 평가 기준(앞으로 유일)**: 적중 = **D+20 종가 < D 종가**(신호일 정규장 종가 기준 · 보합 없음). 적중률 = 그 비율.
- 🟡 일부익절은 별개(§13의 1·3·5일 조정 기준 그대로) — 이 기준으로 평가하지 않는다. 기존 R·Q·ATR 결과는 지우지 않고 '다른 기준의 과거 결과'로 남긴다.
- 고점판독기 화면의 검증 통과 22개(Q 기준)는 이 기준의 결과가 나오면 이 기준으로 다시 판정한다(그 전까지 그대로 · 승인 뒤 교체).

## 설계 (5차 도구 그대로 · `tools/peak-combo-lab.py --only P`)
- 자료: 4차와 같은 시세 캐시(해시 기록) · 탐색 = 관심종목 E·T·X + ZA · **봉인 검증 = ZB**(S&P500·나스닥100 미사용 절반) · 레버리지 따로.
- 조합 공간: 위치 P × {과열 O · 캔들 C · 지표 I · 이탈 K · 외부 X 중 1~4개 역할}(§2 블록 그대로) + 사용자 지정 5 + 기존 조합 대조 3.
- 사건 = 같은 종목·조합 5거래일 안 재발생 제외 · 날짜 가중 적중률(주)과 사건 기준 적중률을 따로.
- 희귀 후보 = 탐색 독립 사건 6↑ ∧ 적중률 65% 초과 → 전부 기록 · 전부 ZB에서 다시 본다(재현 = ZB 6건↑ ∧ 65% 초과). 우연 기대(이항 꼬리) 병기.
- 검증 통과 = ZB 독립 사건 30↑ ∧ 적중률 65%↑(날짜 가중·사건 기준 모두) ∧ 윌슨 90% 하한 55%↑ ∧ 같은 위치 평소 대비 +15%p↑ ∧ 날짜 군집 부트스트랩 하한 > 0 ∧ 한 종목 ≤ 20% · 한 해 ≤ 40%.
- 같이 보고(판정에 안 씀): 20일 평균 수익 · 20일 안 최대 낙폭 중앙 · 상승장/하락장 · 변동성 맞춘 대조(§14 방식, 같은 시세 캐시로 진단).
