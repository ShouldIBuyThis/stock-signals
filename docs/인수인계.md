### 2-1-g. 2026-08-17 계층 재설계 (LOGIC_VERSION v10)

`tools/tier-redesign.js` 신규.

1. **💡이 일반다중보다 +5일 승률이 낮던 원인 — 관문 구조 역전.**
   💡 관문은 `(볼린저≤80 且 당일≤2%) 또는 (RSI≤55 且 거래량≥0.8)`인데
   두 번째 갈래에 **당일 상승률 제한이 없었다.** 상위 계층(OR)이 하위
   계층(일반다중, `볼린저≤68 且 RSI≤60` AND)보다 헐거웠다.
   갈래별로 쪼개니 두 번째 갈래 단독 6건이 +1일 33%·평균 −0.10%로 유일한
   손실 구간이었다. 지우고 나서 💡 78/88/85 → **85/90/88%**, 평균수익도
   전부 상승. 밀려난 6건은 일반다중으로 내려갔다(표본 33→39, +1일 74→69%).

2. **추세 매수관심 재설계 — `볼린저>70` 관문.**
   50/53/50%·평균 −0.26/−0.27/−0.52% → **58/60/61%·평균 +0.19/+0.45/+0.87%**.
   손실이 볼린저 55~70(27/33/23%)·RSI 50~60(43/35/21%)에 몰려 있었다.
   개선분이 전부 급락 구간에서 나온다(전반 43/48/44 → 57/57/62%).
   ⚠ 후반 +3일만 여전히 기준선 아래(59% vs 65%) — 변경 전에도 그랬다.

## 4. 작업 규칙 (요약 — 자세한 건 방법론 문서)

1. **산식을 다시 짜지 마라.** 검증 스크립트는 index.html에서 함수를 문자열로
   추출해 쓴다(`tools/*.js` 전부 이 방식). 두 곳에 두면 반드시 어긋난다.
2. **승률만 보지 마라.** 반드시 같은 구간 기준선 대비 %p로. 컷을 걸 때는
   "지워지는 표본의 성적"을 따로 찍어라 — 승률이 올라도 지운 게 승자 집단이면 착시다.
3. **표본 기준**: 50+ 조정 가능 / 30~50 방향만 / 15~30 참고 / 15 미만 신뢰 불가.
   같은 종목·날짜 겹치면 유효 표본 절반 이하.
4. **과거 hist는 절대 수정 금지** (append-only). hist_fields는 꼬리 추가만 허용.
5. 전·후반 반으로 갈라 양쪽 다 기준선을 넘어야 채택. 한쪽만 좋으면 장세 잔상.
6. 레버리지 상품 판정은 1배 환산(levX 나누기)이 기본.
