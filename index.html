오늘 · 데이터 기준 —
⚠ 모든 지표는 참고용입니다. 박스권·강한 추세장에서는 같은 신호가 반대로 해석될 수 있어요. yfinance는 15~20분 지연된 무료 데이터라 실시간이 아니며, 화면의 수치는 "데이터를 붙여넣은 시점 기준"입니다. 이 화면에는 계좌·잔고 등 개인정보를 절대 넣지 마세요 — 종목과 지표만 다룹니다.

이 화면 사용법

🔄 새로고침
깃허브에 올라간 최신 데이터를 다시 받아옵니다. 새 숫자를 보려면 먼저 Colab을 돌려야 해요.
자동갱신
켜두면 5분마다 알아서 최신 데이터를 받아옵니다. (이것도 Colab을 돌려야 새 값이 생겨요)
📥 데이터 붙여넣기
URL 연동을 안 쓸 때 쓰는 칸이에요. Colab이 출력한 JSON을 여기 붙여넣고 [적용]하면 화면이 갱신됩니다. URL을 이미 저장했다면 안 써도 돼요.
데이터 URL
폰↔컴을 연동하는 링크. 붙여넣기 패널 아래에서 한 번 저장해두면, 이후엔 새로고침만으로 최신 데이터가 옵니다.
2배 숨김
단일종목 2배 레버리지(NVDL·TSLL·APLX)를 숨기고 1배 원주만 봅니다. 움직임이 겹쳐서 헷갈리지 않게요.
☆ 보유 (카드마다)
내가 실제로 가진 종목을 ★로 표시. [보유 숨김]을 켜면 표시한 종목이 화면에서 빠져요.
✕ (카드마다)
그 종목만 잠깐 숨기기. 화면 맨 아래 '숨긴 종목'에서 다시 켤 수 있어요.
⤓ 백업 저장 / ⤒ 백업 열기
관심종목·설정을 파일로 저장하거나 되돌리는 기능. 폰 바꿀 때나 실수로 지웠을 때만 쓰면 됩니다. 평소엔 자동 저장되니 안 써도 돼요.

데이터 붙여넣기 — 언제 쓰나요?

URL 연동을 안 쓸 때 쓰는 칸이에요. Colab이 마지막에 출력한 JSON을 여기 통째로 붙여넣고 [적용]을 누르면 화면이 갱신됩니다.
· 이미 아래 데이터 URL을 저장하셨다면, 이 칸은 안 써도 되고 🔄 새로고침만 누르면 돼요.
· 여기 붙여넣은 데이터는 이 기기에만 저장됩니다.
🔗 데이터 URL (폰↔컴 연동용) — 한 번만 저장: Colab이 결과를 올린 공개 GitHub 링크(raw)를 아래에 넣고 [URL 저장]을 누르세요. 그러면 폰·컴 둘 다 같은 링크를 보고, 새로고침만으로 최신 데이터가 옵니다.
꼭 읽어주세요
· 신호 등급(강한매수~강한매도)은 이동평균·RSI·MACD·볼린저밴드·스토캐스틱·거래량을 2~3개씩 조합한 기계적 판정일 뿐, 매매 추천이 아닙니다.
· 박스권에서는 과매도 신호가 곧바로 반등으로 이어지지 않고, 강한 추세장에서는 과열 신호가 한참 유지되기도 합니다. 반대로 해석될 수 있다는 뜻이에요.
· 데이터 출처는 yfinance(무료·15~20분 지연)이며, 실시간 호가가 아닙니다. 표시된 값은 데이터를 넣은 시점 기준입니다.
· 계좌번호·잔고·개인정보는 이 파일 어디에도 넣지 마세요. 내보내기 파일에도 종목·지표·설정만 저장됩니다.
